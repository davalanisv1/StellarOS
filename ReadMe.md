# StellarOS

StellarOS is a web-based operating system inspired by the movie *Interstellar*. It runs entirely in the browser using HTML, CSS, and vanilla JavaScript. 

## Features

*   **Draggable Windows:** You can drag windows around the screen smoothly by clicking and holding their headers.
*   **Custom Cursor:** The default browser mouse is hidden and replaced with a custom circular pointer that reacts when you click or hover over items.
*   **Notes App:** A built-in scratchpad where you can write notes, switch between them in a sidebar, and save text when you click away (it will stay there as long as the user doesn't refresh the page!).
*   **Weather App:** A detailed weather console tracking real-time conditions for Northville, Michigan. It displays everything from current temperatures and humidity to sunset times and underground soil metrics.

## Project Structure

*   `index.html` - The main structure of the web desktop and application windows.
*   `assets/style.css` - Controls the transparent glass layout, colors, and custom cursor animations.
*   `assets/script.js` - Handles window closing, opening, expanding and dragging mechanics.
*   `assets/weather.js` - Connects to the weather server to fetch and display the live data streams.
*   `assets/notes.js` - A notes app, it does what note taking app does
